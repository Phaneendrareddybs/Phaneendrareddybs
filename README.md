## 🧑‍💻 About Me

I'm an **AI/ML Engineer** working at the intersection of data science and LLM-powered agents.
I like building things end-to-end — from cleaning the raw data, through the model, to a deployed UI someone can actually use.

- 🔭 Currently building **multi-agent systems** with LangChain / LangGraph
- 🌱 Learning more about **RAG evaluation**, **agent orchestration**, and **MLOps**
- 💬 Ask me about **applied ML**, **agentic workflows**, or turning notebooks into products
